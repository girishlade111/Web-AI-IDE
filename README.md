# Web-AI-IDE (Girish AI)

A browser-based AI website builder — describe the website you want in plain English and get a complete, self-contained HTML page generated by Google's Gemini model, with live preview, code view, and export.

## What it does

- **Prompt → website:** type a description ("Create a modern portfolio website for a web developer…") and Gemini (`gemini-2.5-pro`) generates a full single-file HTML page
- **Live preview:** generated site renders instantly in an embedded iframe preview tab
- **Code view:** inspect the generated HTML/CSS/JS in a tabbed code panel, copy it with one click
- **Enhance prompt:** "Enhance Prompt" button rewrites your description into a richer prompt before generation
- **History:** prompt and generated-code history persisted in `localStorage`
- **Export / clear:** download the generated site as an HTML file, or clear the workspace
- **Follow-ups:** refine the current website with additional prompts

## Features

- Single-page app, zero build step — just open `index.html`
- Responsive three-pane layout (prompt panel, tabs, history)
- Dark-styled UI built with vanilla CSS + Font Awesome icons
- Toast notifications, loading overlay, fullscreen preview
- All state local — no backend, no login

## Tech stack

- **HTML5 / CSS3 / vanilla JavaScript** (no frameworks, no bundler)
- **Google Gemini API** (`generativelanguage.googleapis.com`, model `gemini-2.5-pro`) called directly from the browser
- Google Fonts (Inter), Font Awesome 6

## Quick start

No build tools needed — the app is pure static files:

```bash
# just serve the folder (any static server), e.g.:
npx serve .
# or
python3 -m http.server 8000
```

Open http://localhost:8000 (or the port shown). Serving over HTTP is recommended because some browsers restrict module/iframe features on `file://`.

### API key setup (required)

The app calls the Gemini API from the browser, so it needs your own API key:

1. Get a free key at https://aistudio.google.com/apikey
2. In `script.js`, replace the placeholder in the `WebsiteBuilder` constructor:

```js
this.apiKey = 'YOUR_GEMINI_API_KEY';   // was '<redacted>'
```

3. Reload the page — generation now works with your key.

> Security note: the key lives in client-side code, so anyone viewing the page source can see it. Restrict the key in Google Cloud Console (HTTP referrer restrictions) to your deployed domain.

## Project structure

```
index.html                                   # full UI: header, prompt panel, code/preview tabs, history
styles.css                                   # all styling (585 lines, no framework)
script.js                                    # WebsiteBuilder class: Gemini API calls, preview, history, export
Gemini_Generated_Image_8lsgf58lsgf58lsg.png   # logo image ("Girish AI")
```

## Environment variables

None — configuration is the `apiKey` / `apiUrl` fields at the top of `script.js`.

## Deployment

Any static host works (GitHub Pages, Cloudflare Pages, Netlify, Vercel):

```bash
# example: serve/dist folder is just the repo root
cp -r . /path/to/host-root
```
